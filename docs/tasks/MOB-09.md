# MOB-09 — Map và route native

## Mục tiêu

Trực quan hóa toàn bộ lịch trình trên bản đồ và hỗ trợ mở điều hướng thực tế.

## Thay đổi

- Native map tự fit viewport theo các điểm dừng và vị trí hiện tại.
- Hiển thị marker đánh số cùng polyline cho tuyến lịch trình.
- Thêm action xem toàn bộ tuyến đường từ màn hình Plan.
- Thêm deep link mở tuyến trong Google Maps.

## Kiểm tra

`pnpm --filter @wanderly/mobile typecheck && pnpm --filter @wanderly/mobile build`
