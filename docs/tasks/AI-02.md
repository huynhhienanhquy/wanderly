# AI-02 — Thiết kế prompt trích xuất yêu cầu

## Trạng thái

Done — 2026-08-18.

## Kết quả

- System prompt giới hạn model ở nhiệm vụ trích xuất, cấm tự tạo dữ kiện và quy định format ngày/giờ.
- User input được đóng gói dưới dạng JSON cùng timezone/vị trí, không nối trực tiếp vào chỉ dẫn hệ thống.
- Prompt yêu cầu ghi nhận field còn thiếu để UI có thể hỏi lại.

## Kiểm thử

- Test xác nhận input được giữ như dữ liệu và prompt chứa nguyên tắc chống suy diễn.
