# MOB-51 — Settings native

Màn hình cài đặt theme light/dark, lưu lựa chọn bằng SecureStore và có accessibility switch.

## Hoàn thành

- `AppThemeProvider` tải theme đã lưu và cung cấp palette ở cấp ứng dụng.
- Settings áp dụng theme ngay khi đổi, đồng thời lưu lựa chọn cho lần mở sau.
- Status bar tự đổi tương phản theo light/dark theme.
