# AI-01 — Thiết kế PlanningConstraints schema

## Trạng thái

Done — 2026-08-18.

## Kết quả

- Schema dùng chung mô tả ngày/giờ, số người, ngân sách, sở thích, vị trí, bán kính và phương tiện.
- Có default an toàn cho VND, phương tiện, danh sách và trường nullable.
- Validate tọa độ, giới hạn bán kính, độ dài input và quan hệ start/end time.
- Export type cho request/response trích xuất constraint.

## Kiểm thử

- Contract test kiểm tra default và time range không hợp lệ.
