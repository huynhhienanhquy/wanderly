# MOB-47 — Offline status helper

Chuẩn hóa nhận diện trạng thái offline.

## Hoàn thành

- Trạng thái kết nối được cập nhật khi request sự kiện thành công hoặc thất bại.
- Màn hình Events hiển thị cảnh báo có `alert` và `liveRegion` khi dùng cache offline.
- Helper `isOfflineStatus` được sử dụng trong luồng UI thực tế.
