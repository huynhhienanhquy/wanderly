# MOB-03 — Mobile design system

## Mục tiêu

Thiết lập NativeWind, typography, spacing, colors và reusable native components.

## Thay đổi

- Tích hợp NativeWind với Babel, Metro và global Tailwind stylesheet.
- Khai báo brand palette, screen spacing và control/card radius tokens.
- Thêm typed `Button`, `Card` và typography utility presets.
- Áp dụng Card primitive cho Plan route.
- Native components giữ accessibility role và pressed feedback.

## Kiểm tra

`pnpm --filter @wanderly/mobile typecheck && pnpm --filter @wanderly/mobile build`
